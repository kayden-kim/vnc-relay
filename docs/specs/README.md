## 적용 범위와 추적

- [PRD 확정 기준](../requirements/PRD.md#확정-기준)의 사용자 결정을 적용한다. 스펙 5개는 사용자 결정 2026-11-07(Q150)으로 전체를 채택해 Active로 바꿨다. 채택과 검증 완료는 구분한다. 기존 범위의 지원 판정은 [작업 5.9 판정표](../how-to/set-up-and-verify.md#41-작업-59-판정표)를 따른다. OPS-021은 사용자 결정 2026-11-07(Q97)에 따른 루트 LICENSE 작성·검토를 마쳐 통과로 판정했다. 당시 범위의 AC-01~37을 모두 충족했다. 설정 계약 v3의 재로드 확대와 설정 보기·편집은 이전 판정을 적용하지 않고 [작업 6.9 판정표](../how-to/set-up-and-verify.md#42-작업-69-판정표)로 판정했다. 커밋 `eae442f`의 두 OS 게이트에서 확대된 AC-13과 새 AC-38~43을 충족했고, AC-01~37도 회귀 없이 충족했다.
- 각 문서의 규칙 ID는 독립적인 동작을, 시나리오 ID는 그 동작의 수용 조건을 가리킨다. PRD FR ID와 AC ID는 유지한다.
- [PRD의 추적 표](../requirements/PRD.md#14-관련-스펙과-추적)가 기능·보안·비기능 기준을 스펙과 시나리오에 연결한다.
- 업무 용어는 루트 [용어집](../../GLOSSARY.md)을 따른다.
- 수용 테스트 표는 시나리오와 기대 결과만 정의한다. 시나리오와 테스트의 연결은 테스트 소스 코드의 메타 정보로, 커버리지·결과는 메타 정보에서 생성한 보고서로 관리한다([검증 기록](../AGENTS.md#검증-기록)). 메타 정보 문법과 보고 명령은 [테스트 컨벤션](../conventions/testing.md)이 정한다. 보고서는 `cargo xtask scenarios`가 Cargo 대상 디렉터리의 `scenario-report.md`로 만든다. 시나리오별 연결과 결과는 이 보고서에서 확인하며 이 문서에는 적지 않는다. 테스트와 연결되지 않은 시나리오는 보고서에 `미연결`로 나온다. 문서 검증을 통신·UI·호환성 테스트 통과로 간주하지 않는다.
- 교환 계약 6건 중 설정·CLI·관리 API·WebSocket·운영 정보 5건은 2026-10-16에 사용자가 채택해 [계약 목록](../contracts/README.md)에 Active로 등록했다. Repeater 초기 교환 계약은 관찰 증거로 형식을 확정해 2026-11-01에 채택했다(사용자 결정 2026-11-01(Q73)). 같은 날 중복 ID 정책(RLY-TBD-003)도 후발 거절로 정했다(Q74·Q75). 설정 계약은 2026-11-01에 2.0.0으로 올렸고(Q71), 2026-11-08에는 재로드 범위 확대에 따라 [v3(3.0.0)](../contracts/config-v4.md)으로 올렸다(사용자 결정 2026-11-08(Q168·Q171)). v2 파일은 고치지 않고 v3 서버에서 읽는다. 각 계약 5절이 계약 테스트의 위치와 결과를 관리한다. 실제 지원 판정은 [작업 5.9 판정표](../how-to/set-up-and-verify.md#41-작업-59-판정표)를 따른다. 기본값과 유효 범위의 수치와 TCP 진입점 기본 포트는 사용자가 승인했고 [설정 계약](../contracts/config-v4.md)이 기준이다. 허용 암호 스위트는 선택한 rustls 암호 모듈의 rustls 기본 목록으로 확정했다. Rust 라이브러리는 [PRD](../requirements/PRD.md#확정-기준) "구현 기술" 행이 기준이며 2026-10-20 의존성 라이선스 검토 뒤 확정했다. 대시보드 시각 기준은 [디자인 기준](../design/DESIGN.md)(2026-10-20 채택)이 정한다. rustls 암호 모듈(OPS-TBD-009)은 aws-lc-rs로 정해 해소했다. 고정 검증 버전은 [호환성 검증 기록](../contracts/repeater-compat-record.md)이 정한다(Ubuntu Repeater는 보류, 사용자 결정 2026-10-22(Q19)). 성능 측정 환경과 합격 수치(OPS-TBD-004)는 사용자 결정 2026-11-04(Q98)로 [운영 스펙 6절](operations.md#6-비기능호환성출처-수용-조건)에 정해 해소했다. 출처·MIT 고지 검토(OPS-TBD-005, OPS-021)는 운영 스펙의 미결정 표에서 관리한다.

후속: 2026-11-08. 사용자 지시 2026-11-08과 사용자 결정 2026-11-08(Q181~Q188)로 WS·WSS Server·프록시 TLS 종료·최근 로그 화면을 더했다. 현재 기준은 [vnc-relay-config 4.0.0](../contracts/config-v4.md)과 [ops-info 2.0.0](../contracts/ops-info-v2.md)이다. v4 서버는 v3 파일을 거절하므로 [설정 계약 3.3절](../contracts/config-v4.md#33-v3-파일을-v4로-옮기기)의 이전·롤백을 따라야 한다. 위 v2→v3 호환 설명은 당시 기록이다. 새 범위의 구현은 커밋 `3df0693`이다. 커밋 `51bd747`의 두 OS 게이트와 [WSS Server·프록시·최근 로그 판정표](../how-to/set-up-and-verify.md#43-wss-server프록시-tls-종료최근-로그-판정표)로 AC-44~48을 충족했다. 이전 판정표를 새 범위의 완료 증거로 쓰지 않는다.

- 환경: Windows, Python 3.14.6, markdown-it-py 4.2.0.
